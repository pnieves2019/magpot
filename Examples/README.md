
This folder contains examples on how to use ```MagPot``` code. 

-------------------------
STEP1 - EOS
-------------------------

In the folder ```Step1_eos```, there is the calculation of the Equation of State (EOS) for bcc Fe in order to derive the equilibirum distance between the nearest neighbors (r0) and bulk moudlus (B0) without magnetic interactions required as input parameters for ```MagPot``` code.  

-------------------------
STEP2 - MAGPOT
-------------------------

In the folder ```Step2_magpot```, there is the calculation of the magnetoelastic potential for ferromagnetic bcc Fe using the ```MagPot``` code. In the file ```input.dat```, we set the equilibirum distance between the nearest neighbors (r0) and bulk moudlus (B0) without magnetic interactions obtained in folder ```Step1_eos```. 

-------------------------
TESTS
-------------------------

In the folder ```Tests```, we provide tests to verify that the magnetoelastic potential generated by ```MagPot``` code reproduces the desired Curie (or Neel) temperature, spontaneous volume magnetostriction (w_s), pressure dependence of magnetocrystalline anisotropy K1(P) and anisotropic magnetoelastic constants (b) correctly. The obtained results in these tests should coincide with the corresponding input data given by the file ```input.dat``` in the folder ```Step2_magpot```. Each test can be executed by running the file ```run.sh``` inside the corrresponding input folder. The results of each test are given in the output folder. For the test of the magnetoelastic constants b1 and b2 (folder ```Test_b1_b2```), it is required to install the programs ```MAELAS``` 

[https://github.com/pnieves2019/MAELAS](https://github.com/pnieves2019/MAELAS)

and  ```ATOMSK```

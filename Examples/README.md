# MagPot examples

This directory contains example calculations illustrating how to use **MagPot** to generate magnetic interaction parameters for spin–lattice molecular dynamics simulations with the SPIN package of LAMMPS.

The examples are organised as a three-stage workflow: (1) determine the structural parameters of the spin-independent reference system from an equation-of-state calculation, (2) generate the magnetic contribution with MagPot, and (3) test the resulting spin–lattice model against the target magnetic and magnetoelastic properties.

## Directory structure

The examples are grouped into the following directories:

| Directory | Purpose |
|---|---|
| `Step1_eos/` | Equation-of-state (EOS) calculation for body-centred-cubic (BCC) Fe, used to determine the equilibrium first-neighbour distance, $r_{NN}$, and bulk modulus, $B_0$, of the spin-independent reference system. |
| `Step2_magpot/` | Generation of the magnetic interaction parameters for ferromagnetic BCC Fe using MagPot. The `input.dat` file uses the structural parameters obtained in `Step1_eos/`, together with the target magnetic and magnetoelastic properties. |
| `Tests/` | Validation calculations for the magnetic and magnetoelastic properties of the generated spin–lattice model. |

## 1. Equation of state: `Step1_eos/`

The first step is to calculate the EOS of BCC Fe using the spin-independent reference potential, with the magnetic exchange and Néel interactions switched off. The energy–volume data are fitted to an EOS to obtain:

- the equilibrium first-neighbour distance, $r_{NN}$;
- the bulk modulus, $B_0$.

These two quantities characterise the reference lattice contribution and are required inputs for MagPot. Use the values obtained from this calculation in the `input.dat` file in `Step2_magpot/`.

## 2. Generation of the magnetic interactions: `Step2_magpot/`

The second step uses MagPot to generate the magnetic contribution for ferromagnetic BCC Fe.

The `input.dat` file contains the structural parameters, $r_{NN}$ and $B_0$, obtained in `Step1_eos/`, together with the target magnetic and magnetoelastic properties. Run MagPot from this directory following the instructions in the main repository README and User Manual.

MagPot prints the Bethe–Slater parameters and the corresponding LAMMPS `pair_coeff` commands for the Heisenberg exchange and two-ion Néel interactions. These magnetic contributions must be combined in LAMMPS with the separately supplied spin-independent reference potential using `pair_style hybrid/overlay`.

## 3. Validation tests: `Tests/`

The `Tests/` directory contains calculations to assess whether the generated spin–lattice model reproduces the target properties specified in `Step2_magpot/input.dat`. The tests cover:

- the Curie temperature (or Néel temperature, where applicable);
- spontaneous volume magnetostriction, $\omega_s$;
- the pressure dependence of the first magnetocrystalline-anisotropy constant, $K_1(P)$;
- the anisotropic magnetoelastic constants, $b_1$ and $b_2$.

### Running a test

Each test is run from its corresponding input directory. Open a terminal, move to the directory containing that test's `run.sh` script, and execute:

```bash
chmod +x run.sh
./run.sh
```

The calculation results are written to the corresponding `output/` directory. Compare the recovered properties with the target values in `Step2_magpot/input.dat`. Agreement should be assessed for each property separately; small differences can arise from the finite-temperature spin-dynamics procedure and from the numerical fitting of the calculated data.

### Additional requirements for the magnetoelastic-constant test

The test in `Test_b1_b2/` also requires:

- [MAELAS](https://github.com/pnieves2019/MAELAS), to generate the strained structures and perform the strain–energy analysis;
- [Atomsk](https://atomsk.univ-lille.fr/), to convert the generated atomic structures into LAMMPS data files.

Install and configure these programs before running that test. Follow their respective documentation for installation and usage instructions.

## Notes

- The example workflow is designed for BCC Fe and illustrates the complete parameterisation and validation procedure. MagPot itself supports additional cubic lattices and magnetic configurations; see the main repository README and User Manual for the supported cases.
- The quantities $r_{NN}$ and $B_0$ refer to the spin-independent reference system, calculated without the magnetic exchange and Néel contributions.
- The magnetic interaction parameters generated by MagPot do not replace the reference interatomic potential. Both contributions are required for the spin–lattice simulations described here.
- Check the LAMMPS input files and the paths to the required executables before running the shell scripts. Adapt them to your local LAMMPS installation and computing environment when necessary.

## References and further information

For the program installation, input-file format, theoretical background, and detailed description of the generated LAMMPS commands, consult the main [MagPot repository](https://github.com/pnieves2019/magpot) and the `User_Manual.pdf` file provided there.

For the underlying spin–lattice model, see:

P. Nieves, J. Tranchida, S. Arapan, and D. Legut, “Spin-lattice model for cubic crystals,” *Physical Review B* **103**, 094437 (2021). [https://doi.org/10.1103/PhysRevB.103.094437](https://doi.org/10.1103/PhysRevB.103.094437).
